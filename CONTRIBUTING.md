# Contributing to DSi-FC-Men

Thank you for your interest in improving DSi-FC-Men!

## How to contribute

1. Fork the repository
2. Create a new branch (`feature/your-feature` or `fix/bug-name`)
3. Make your changes
4. Test on real hardware if possible
5. Open a Pull Request with a clear description

## Code style
- C for the main menu and Setupper
- Keep functions small and focused
- Comment non-obvious parts
- Use the existing config system instead of hardcoding values

## Priority areas
- Completing the file browser + nds-bootstrap launch
- Real sound loading (ndsp + bcwav)
- Theme system (backgrounds from SD)
- Soft-reset
- Better Setupper UI
- Pure NDS (libnds) version for classic flashcards

## Questions
Open an Issue or Discussion on GitHub.
