nds-bootstrap for DSi-FC-Men
============================

This folder must contain the nds-bootstrap files.

DOWNLOAD (required):
  https://github.com/DS-Homebrew/nds-bootstrap/releases/latest

Extract the release and place these files HERE:

  Required:
    nds-bootstrap-release.nds
    nds-bootstrap-hb-release.nds   (for homebrew)

  Optional but recommended:
    nds-bootstrap.ini
    B4DS-release.nds              (for DS flashcards)
    nightly versions if you want

After placing the files, DSi-FC-Men can launch .nds ROMs
using nds-bootstrap as the loader.

Alternative: Use TWiLight Menu++ and copy only the
/_nds/nds-bootstrap/ folder from it.
