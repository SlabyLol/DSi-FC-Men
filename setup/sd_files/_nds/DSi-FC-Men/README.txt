DSi-FC-Men – DSi FlashCard Menu
================================

SETUP COMPLETE

1. Put your Nintendo DS ROMs (.nds) into:
   /roms/nds/

2. Saves are stored automatically in:
   /saves/

3. Edit settings in:
   /_nds/DSi-FC-Men/config.ini

4. Optional:
   - Themes  → /_nds/DSi-FC-Men/themes/
   - Boxarts → /_nds/DSi-FC-Men/boxart/
   - Sounds  → /_nds/DSi-FC-Men/sounds/

5. Place latest nds-bootstrap files into:
   /_nds/nds-bootstrap/

Download nds-bootstrap from:
https://github.com/DS-Homebrew/nds-bootstrap/releases

Enjoy!
